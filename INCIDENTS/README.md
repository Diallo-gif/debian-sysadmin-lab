# Gestion des incidents – Debian 13

## Présentation

Simulation de 7 incidents techniques dans un laboratoire Debian 13 sous VMware Workstation.

**Objectif :** développer mes compétences en diagnostic, dépannage et administration Linux.

## Liste des incidents

| N° | Incident |
|---|---|
| 01 | Accès refusé au dossier Finance |
| 02 | Serveur sans accès Internet |
| 03 | Résolution DNS en panne |
| 04 | Connexion SSH inaccessible |
| 05 | Service interne indisponible |
| 06 | Espace disque presque saturé |
| 07 | Problème de compte et privilèges |

## Méthodologie

1. Identification du problème
2. Diagnostic et analyse
3. Correction de l'incident
4. Vérification du résultat
5. Documentation technique

## Compétences développées

Administration Linux, gestion des permissions, diagnostic réseau, services système, stockage et résolution d'incidents.
